How a model learns, in one loop

Forward, loss, backward, step, repeat. The weights are what you keep.

Forward: make a prediction Backward: gradients Update: optimizer

The training loop

Every step: predict, measure the error, assign blame, nudge the weights, forget the gradients.

forwardpredict with current weights
losshow wrong (never exactly 0 in practice)
backwardgradients: which direction to move each weight, and how strongly
stepoptimizer updates the weights using the gradients
discardgradients thrown away, recomputed next step
repeat

Who's who

Only parameters are learned and kept. Everything else is temporary.

ThingLearnedKept
Parameters ("weights")W, biases, embeddings, norm gains
Activationsh1 = relu(x @ W1): one layer's output, the next layer's input. Held in memory until backward(), then freed
Gradientsw.grad = ∂loss/∂w, recomputed every step
Lossone number per step: how wrong
Inputsx, the data
Hyperparameterslearning rate, layers, batch size: you set them

Rule of thumb: the optimizer updates it → parameter. You set it → hyperparameter. Recomputed each forward pass → activation.
Parameters are what each layer is. Activations are what flows through the layers.

Worked by hand

x = [1, 2, 3], w = [1, 1, 1], target = 5

Predictx @ w = 6
Loss½ (6 − 5)² = 0.5
Gradient(6 − 5) · x = [1, 2, 3]
Stepw − 0.1 · grad = [0.9, 0.8, 0.7]
Predictx @ w = 4.6 (overshot 5; lr is big)

The ½ cancels the 2 from the square. w3 gets the biggest gradient because it multiplies the biggest input. The lecture's "y" is this loss.

Gradient descent

The gradient points uphill. The optimizer steps the other way.

w ← w − lr × grad

Steps shrink near the bottom because the gradient shrinks with the error. Ascent (+ lr × grad) maximizes something instead, like reward in RL.

Activation functions

Without them, x @ W1 @ W2 = x @ W. Stacked layers collapse into one.

x→ layer 1 →h1→ layer 2 →h2→ … →logits

The activation function (ReLU, GELU) is the bend inside each layer. The activations (h1, h2) are the values it outputs, passed on as the next layer's input. In a transformer each block adds to them instead: h = h + block(h).

They sit in the MLP block: W2 @ act(W1 @ x). In the backward pass their slope gates the gradient (ReLU: 1 or 0).
